画面と機能

データ管理

STL＋CSVのサンプル（1サンプル＝1形状・1鋳造条件）の登録・一覧・検索・詳細。

バージョン管理

閉ループ解析の考え方

鋳物は表面に近い所から固まります。固まる途中で、まだ液体の部分が周囲を先に固まった金属に囲まれて孤立すると、押湯から溶湯を補給できず、そこが固まるときの縮みで引け巣ができやすくなります。この孤立した液相を閉ループと呼び、凝固時間の分布から自動で見つけます。

時刻 t₁（注湯直後）

全体が液体で、押湯とつながっている。

時刻 t₂（孤立時刻）

薄い板が先に固まり、厚いボスの液体が押湯から切り離される（閉ループ）。

時刻 t₃（ピーク）

ボスの中心が補給なしで最後に固まる。ここが引け巣のリスク部。

つながっている液相（押湯から補給できる） 孤立した液相（閉ループ） 凝固済み
項目意味
孤立時刻その液相が周囲から切り離される時刻（図の t₂）
ピーク閉ループの中で最後に固まる点の凝固時間（図の t₃）
Δt（危険度）ピーク − 孤立時刻。孤立したまま固まる時間で、長いほど補給されずに縮む量が大きい
最終凝固部最後まで吸収されない液相（押湯など）。閉ループには数えない
探索範囲「つながっている」とみなす隣の範囲。6近傍（面）・18近傍・26近傍 × 半径1〜4、または層ごとに任意に指定

凝固時間の遅い順にボクセルを足していき、液相のかたまりが合流する瞬間を記録する方法（Union-Find による max-tree）で、全時刻のつながり方を1回の走査で求めます。最小Δt と最小体積で小さなノイズを除きます。

ML Process Lab の予測を開く

  1. Lab の「モデル・予測」画面で、出力先に surrogate-manager/data/results を選んで予測する
  2. Manager の「フィールド可視化」で、data/ 配下の一覧からその予測CSVを選ぶ（ドラッグ＆ドロップでも可）
  3. 探索範囲と最小Δt を決めて解析し、閉ループの一覧からクリックで位置を確認する

CSVは x, y, z, 値 の列（2mm角などのボクセル）。ピッチは座標から自動判定し、Shift_JIS（Excel保存）にも対応しています。

技術構成と起動

画面は React ＋ TypeScript（three.js で3D）、サーバは FastAPI ＋ SQLite（チーム運用では PostgreSQL を想定）。Electron でデスクトップアプリにもできます。Windows は start.bat をダブルクリックで起動し、ブラウザで http://localhost:5173 が開きます。
